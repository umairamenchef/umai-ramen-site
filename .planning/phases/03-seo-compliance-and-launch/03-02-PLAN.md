    - Export `COOKIE_NAME = 'umai_consent'`

    - Export `type ConsentValue = 'accepted' | 'rejected' | null`
    - Export `getConsent(): ConsentValue` — reads `document.cookie`, returns 'accepted', 'rejected', or null
    - Export `setConsent(value: 'accepted' | 'rejected'): void` — writes cookie with max-age, path=/, SameSite=Lax
    - Export `updateGtagConsent(granted: boolean): void` — calls `window.gtag('consent', 'update', { analytics_storage, ad_storage, ad_user_data, ad_personalization })` with 'granted' or 'denied' for each

    **4. Add GTM scripts and CookieBanner to `src/app/[locale]/layout.tsx`:**

    **CRITICAL ORDER — Consent defaults MUST execute BEFORE GTM loads:**

    a. Add a synchronous `<script>` tag in the `<head>` section (inside `<html>`) BEFORE any other scripts. This sets Consent Mode v2 defaults to ALL DENIED:
    ```tsx
    <head>
      <script
        dangerouslySetInnerHTML={{
          __html: `
            window.dataLayer = window.dataLayer || [];
            function gtag(){dataLayer.push(arguments);}
            gtag('consent', 'default', {
              'analytics_storage': 'denied',
              'ad_storage': 'denied',
              'ad_user_data': 'denied',
              'ad_personalization': 'denied',
              'wait_for_update': 500
            });
            gtag('js', new Date());
          `,
        }}
      />
    </head>
    ```

    b. Add GTM container script using next/script with `strategy="afterInteractive"` — AFTER the consent defaults:
    ```tsx
    import Script from 'next/script';
    // ... inside the body, after NextIntlClientProvider:
    {process.env.NEXT_PUBLIC_GTM_ID && (
      <Script
        id="gtm-script"
        strategy="afterInteractive"
        src={`https://www.googletagmanager.com/gtm.js?id=${process.env.NEXT_PUBLIC_GTM_ID}`}
      />
    )}
    ```
    Gate on `process.env.NEXT_PUBLIC_GTM_ID` existence so dev builds without the env var don't throw.

    c. Add `<CookieBanner />` as the LAST element inside the `<body>` (after MobileBar), so it renders on top of everything:
    ```tsx
    import { CookieBanner } from '@/components/consent/CookieBanner';
    // ... at the end of body content:
    <CookieBanner />
    ```

This allows GTM to capture CTA click conversions via tag configuration — no custom JS event handlers needed. The actual GTM tag/trigger setup is done in the GTM dashboard by the owner, not in code.

    This is optional — GTM can capture clicks via CSS selectors. Document the approach in the SUMMARY for the owner's GTM configuration.
