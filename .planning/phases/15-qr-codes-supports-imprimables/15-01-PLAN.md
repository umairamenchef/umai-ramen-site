
`qrcode` 1.5.4 (npm, MIT; deps pngjs ^5, yargs ^15, dijkstrajs; CommonJS `module.exports = require('./server')`, so `import QRCode from 'qrcode'` works in ESM):
- `QRCode.create(text, { errorCorrectionLevel: 'Q' })` returns `{ modules, version, errorCorrectionLevel, maskPattern, segments }`; `modules` is a BitMatrix with `size` (29 for version 3) and `data` (Uint8Array, row-major, 1 = dark). `errorCorrectionLevel` is `{ bit: 3 }` for Q.
- `await QRCode.toFile(path, text, { type: 'png', errorCorrectionLevel: 'Q', margin: 4, scale: 28, color: { dark: '#000000ff', light: '#ffffffff' } })` writes a PNG of `floor((size + 2·margin) · scale)` px = 37 × 28 = 1036 px, pure black/white (each pixel maps to one module, no anti-aliasing). Do NOT pass `width` (it would force 1024 px and uneven 27/28 px modules).
- Its built-in SVG renderer draws modules as 1-unit STROKES (`<path stroke=… d="M4 4.5h7…">`); this plan does not use it: `qrSvg` in `src/lib/qr.ts` draws filled squares instead (clean in print and in PDF).

`jsqr` 1.4.0 (npm, Apache-2.0, no dependencies): `jsQR(data: Uint8ClampedArray /* RGBA */, width, height, { inversionAttempts }) → { data, version, location: { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner, … } } | null`.
- EXPORT QUIRK: the UMD bundle sets `module.exports = { default: jsQR }` (`exports.default = jsQR`), so in ESM use
  `import jsQRModule from 'jsqr'; const jsQR = typeof jsQRModule === 'function' ? jsQRModule : jsQRModule.default;`

Capacity facts: every URL `https://umai-ramen.fr/xx/menu` is 29 bytes (byte mode). Version 2-M holds 26 bytes, version 3-M 42, version 3-Q 32, version 3-H 24. So level Q costs nothing over M (both version 3, 29 × 29 modules): CONTEXT « M (or Q if the layout allows) » → Q.

`mutool` 1.27.2 is at /usr/local/bin/mutool and renders PDF, SVG and PNG to binary PGM:
- `mutool draw -q -w 740 -o out.pgm file.svg` (SVG with `width="37mm"` renders fine), `mutool draw -q -w 1036 -o out.pgm file.png`, `mutool draw -q -r 300 -o page-%d.pgm file.pdf`
- PGM header = `P5\n<width> <height>\n255\n` then width × height gray bytes.

Live facts (read-only GETs, 2026-11-24): https://umai-ramen.fr/{fr,en,de,it,zh}/menu answer 200 directly (no redirect) with `<html lang="fr|en|de|it|zh-Hans"`; the menu pages carry `data-menu-locale-switcher`. `/fr/menu/qr` is 404 today (Plan 03 adds it).
