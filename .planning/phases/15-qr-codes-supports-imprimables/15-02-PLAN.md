pypdf 6.9.2 box normalisation that worked (top-left of the content stays at the top-left):
```python
from pypdf import PdfReader, PdfWriter, Transformation
from pypdf.generic import RectangleObject
MM = 72 / 25.4
W, H, B = w_mm * MM, h_mm * MM, bleed_mm * MM
for page in reader.pages:
    page.add_transformation(Transformation().translate(0, H - float(page.mediabox.top)))
    page.mediabox = page.cropbox = page.bleedbox = RectangleObject([0, 0, W, H])
    page.trimbox = RectangleObject([B, B, W - B, H - B])
    writer.add_page(page)
```
