   - Export TS types `IgEntry`, `IgPhoto`.
3. **src/app/api/ig-studio/photo/[id]/route.ts**:
   - `export const dynamic = 'force-dynamic';`
   - `GET(req, { params })`: `await requireStudioAuth()` (catch → 401). `const { id } = await params;` if `!isValidPhotoId(id)` → 404. `const p = photoFsPath(id);` if `!existsSync(p)` → 404.
   - `const size = new URL(req.url).searchParams.get('size');`

   - Else stream/return the full file: `const buf = await readFile(p);` return it as `image/jpeg` (full-res streaming via a ReadStream is also fine; a buffer is acceptable for a 3-user local tool).
