<objective>
Extend the existing `ig-studio/src` compositing pipeline so the web editor (Plans 07-03/04/05) can drive it against the CANONICAL `menu-options.json` and the human's in-flight choices — WITHOUT duplicating any rendering logic. Three glue pieces: (1) a `menu.js` loader for the canonical dropdown/NAP, (2) an `overlay.js` extension that honours an explicit overlay mode + human-supplied dish name/price, and (3) `compose.js` single-photo + preview CLI modes. Keeping all compositing/caption logic in `ig-studio` avoids bundling native `sharp` into Next and sidesteps cross-package module resolution. This plan is pure ig-studio Node work — independent of the Next app — so it runs in parallel with 07-01.
Output: `menu.js` (+ test), extended `overlay.js`/`overlay.test.js`, extended `compose.js` CLI, new `caption.js`, and npm scripts.
