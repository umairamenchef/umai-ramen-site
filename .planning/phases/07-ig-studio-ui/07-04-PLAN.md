<objective>
Build the heart of the tool: the per-photo editor at `/ig-studio/{id}` where Loan finalizes each post in a few clicks (REVIEW-03 classification override, REVIEW-04 caption, REVIEW-05 regenerate). It renders the photo + AI suggestion, a grouped dish dropdown (canonical menu-options) that auto-fills price/baseline, an overlay-mode toggle, a caption field with a "Générer caption" button, a live preview of the composed feed image, and Save / Regenerate actions. The Next app stays thin: server actions write the JSON stores directly via fs and SHELL OUT to the ig-studio Node modules (07-02) for compositing + caption drafting.

Purpose: This subsumes Phase 06's manual finalization — the editor is where wrong AI labels get corrected and the real branded post + caption are produced. Override-wins persistence means corrections survive re-runs and downstream steps.
Output: a `run.ts` spawn helper, server actions, a preview API route, the editor server component, and the `<PhotoEditor>` client component.
</objective>
