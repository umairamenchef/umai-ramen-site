   - `export const COOKIE_NAME = 'ig_studio_auth';`
   - `async function sha256Hex(s: string): Promise<string>` using `globalThis.crypto.subtle.digest('SHA-256', new TextEncoder().encode(s))` → hex string.
   - `export async function expectedToken(): Promise<string | null>` — reads `process.env.IG_STUDIO_PASSWORD`; returns `null` if unset/empty, else `sha256Hex(password)`.
   - `export async function isValidStudioCookie(value: string | undefined): Promise<boolean>` — `false` if no value or no expected token; else constant-ish compare `value === expected`.
   - `export async function requireStudioAuth(): Promise<void>` — for Node server contexts (route handlers / server actions): `const { cookies } = await import('next/headers'); const jar = await cookies(); const ok = await isValidStudioCookie(jar.get(COOKIE_NAME)?.value); if (!ok) throw new Error('UNAUTHORIZED');` (callers in later plans turn this into a 401 / redirect).

2. **src/proxy.ts** — replace the bare `createMiddleware` export with a custom async proxy:
   ```ts
   import createMiddleware from 'next-intl/middleware';
   import { NextResponse, type NextRequest } from 'next/server';
   import { routing } from './i18n/routing';
   import { COOKIE_NAME, isValidStudioCookie } from './lib/ig-studio/auth';

   const intl = createMiddleware(routing);

   export async function proxy(req: NextRequest) {
     const { pathname } = req.nextUrl;
     if (pathname === '/ig-studio' || pathname.startsWith('/ig-studio/')) {
       if (pathname === '/ig-studio/login') return NextResponse.next();
       const ok = await isValidStudioCookie(req.cookies.get(COOKIE_NAME)?.value);
       if (!ok) {
         const url = req.nextUrl.clone();
         url.pathname = '/ig-studio/login';
         return NextResponse.redirect(url);
       }
       return NextResponse.next(); // bypass next-intl entirely for the admin tool
     }
     return intl(req);
   }
   ```
   - Keep the existing `export const config = { matcher: '/((?!api|trpc|_next|_vercel|studio|.*\\..*).*)' };` UNCHANGED — `/ig-studio` is already matched by it; `/api/ig-studio/*` stays excluded (auth handled in those routes via `requireStudioAuth`).
