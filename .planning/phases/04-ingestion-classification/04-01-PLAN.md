<objective>
Build the Umaï IG Content Studio classification CLI under `ig-studio/`. It reads the 81 already-local photos (`ig-studio/photos/umai_001.jpg…umai_081.jpg`), classifies each via Claude Vision (`claude-opus-4-8`) against the SUMMER 2026 menu knowledge base, and emits a human-editable `ig-studio/classification.json`. A `--pilot` flag classifies ~10 varied photos; `--all` (81) is gated behind a pilot sign-off marker.

Purpose: This is the entry point of the whole v2.0 studio pipeline. Phases 05 (compositing) and 06 (captions) read the human-corrected `classification.json`, so the override-wins merge and the broth disambiguation accuracy matter most.
Output: A runnable Node CLI that produces `classification.json` from local photos, with a working pilot gate.
</objective>

<classification_contract>
classification.json is an array; each entry:
```json
{
  "file": "umai_007.jpg",
  "dishSlug": "tokyo",
  "shotType": "packshot",
  "confidence": 0.82,
  "reasoning": "Clear broth + pork chashu + bamboo → Tokyo per summer KB.",
  "override": false
}
```
- `dishSlug` is "ambiance" when `shotType` is "ambiance"; otherwise one of the valid slugs derived from the summer menu (see kb.js).
- `override: true` means a human edited the entry → re-runs MUST NOT overwrite it.
