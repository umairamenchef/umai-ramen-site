## Integration Issues

### High — Hero image never renders (HOME-01)
`Hero.tsx` accepts `heroImage` prop but `page.tsx` never passes one. `HOMEPAGE_QUERY` doesn't fetch a hero image. `siteSettings` schema has no `heroImage` field. Hero always shows solid black background.
**Fix:** Add `heroImage` to siteSettings schema + HOMEPAGE_QUERY + page.tsx prop.

### Medium — Button uses raw next/link (FOUND-03, HOME-05, HIST-04)
`Button.tsx` imports `Link` from `next/link` (raw) instead of `@/i18n/navigation` (locale-aware). Internal Button navigation causes redirect round-trips and potential locale loss on `/en` and `/de` pages.
**Fix:** Change import to `{ Link } from '@/i18n/navigation'`.

### Low — Footer data hardcoded (LAYT-04, INTG-06, INTG-07)
Footer phone number, Instagram URL, and Facebook URL are hardcoded strings. Layout only passes `reservationUrl` and `uberEatsUrl`. Documented deferral to Phase 3.

### Low — SocialSection handle hardcoded (HOME-07)
`@umai_ramen_strasbourg` is a hardcoded string. The `instagramUrl` prop is Sanity-driven but the visible handle text is not.
