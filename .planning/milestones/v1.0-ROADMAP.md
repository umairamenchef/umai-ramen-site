# Milestone v1.0: MVP Launch

**Status:** ✅ SHIPPED 2026-02-23
**Phases:** 1–3
**Total Plans:** 11

## Overview

Complete website redesign for UMAI Ramen, replacing an aging Gulp/Nunjucks one-pager with a modern Next.js 16 / Sanity v5 multilingual site. Three phases deliver the full stack: Phase 1 locks in structural decisions (scaffold, CMS schemas, trilingual routing, design system); Phase 2 assembles all 7 content pages with Sanity data and external integrations; Phase 3 covers SEO metadata, RGPD/CNIL compliance, on-demand revalidation, and a Lighthouse performance audit — then ships to production.

Deployed to VPS srv1417179 via docker compose (`umai`) behind Caddy reverse proxy, accessible at umai.turfu.in (staging). Production domain umai-ramen.fr pending DNS cutover.

## Phases

### Phase 1: Foundation

**Goal**: A buildable, deployable project where every route is statically generated, Sanity Studio is accessible at /studio, trilingual locale routing works end-to-end, and the design system is ready for page assembly
**Depends on**: Nothing (first phase)
**Plans**: 3 plans

Plans:

- [x] 01-01: Next.js 16 scaffold with App Router, TypeScript, Tailwind CSS 4, proxy.ts middleware, next-intl v4 trilingual routing, ISR 60s baseline, webhook stub
- [x] 01-02: Sanity v5 schemas (siteSettings, menuCategory, menuItem, gallery, page), field-level localeString i18n, sanityFetch helper, GROQ queries, TypeGen, Studio at /studio
- [x] 01-03: Design system tokens (@theme), self-hosted fonts (DM Serif Display, Outfit, Noto Sans JP), LazyMotion wrapper, Header, MobileMenu, MobileBar, Footer with seigaiha, UI primitives

**Details:**
- `proxy.ts` exports `const proxy` (breaking change from Next.js 16 — not default export)
- `localePrefix: always` forces explicit `/fr`, `/en`, `/de` prefixes (root `/` redirects 307 to `/fr`)
- `__experimental_actions` removed (deprecated in Sanity v5); singleton enforced via `structure.ts` single documentId
- `sanityFetch` with `tags.length > 0` sets `revalidate=false` to avoid mixing time + tag revalidation
- LazyMotion `domAnimation` reduces motion bundle from ~34kb to ~4.6kb
- Noto Sans JP `preload: false` — decorative-only font, lazy-loaded to protect LCP
- `@theme inline` block in Tailwind 4 prevents purging font utilities set by next/font at runtime

### Phase 2: Content Pages

**Goal**: A fully navigable multilingual site where visitors can browse the menu, learn UMAI's story, view photos, find contact info, and reach Gusty/Uber Eats in one click
**Depends on**: Phase 1
**Plans**: 5 plans

Plans:

- [x] 02-01: Shared infrastructure — urlFor helper, FadeInUp wrapper, localized() utility, menuExtra/menuFormule Sanity schemas, GROQ queries, i18n messages, outline-white Button variant
- [x] 02-02: Homepage (Accueil) — fullscreen hero, menu preview cards, USP blocks, Notre Histoire teaser, gallery preview, social section
- [x] 02-03: Menu page — Sanity-driven categories/items, sticky sub-nav, dietary badges, extras grid, formules section, eazee-link CTA
- [x] 02-04: Remaining pages — Reservation (Gusty CTA, practical info), Commander (3 ordering cards), Notre Histoire (scroll storytelling), Infos (hours, maps, FAQ), Gallery (CSS grid + lightbox)
- [x] 02-05: Visual and functional verification checkpoint for all 7 content pages

**Details:**
- `SanityImageSource` type imported from `@sanity/image-url` directly (v2 package root)
- `sanityFetch` in root layout wrapped in try/catch — graceful fallback when Sanity credentials not configured
- `menuFormule.includedItems` uses array of string (not localeString) — format-specific, not translated
- `next/image` uses `loading=eager` (not `priority`) for Hero — `priority` deprecated in Next.js 16
- `NEXT_TURBOPACK_USE_WORKER=0` required for `next build` in WSL2 — Turbopack worker race condition
- `createImageUrlBuilder` named export replaces deprecated default export from `@sanity/image-url`
- GalleryGrid and GalleryLightbox merged into single client component — lightbox state must be co-located with grid click handlers
- Commander page shows 'Bientôt disponible' text when `clickCollectUrl` is null/empty

### Phase 3: SEO, Compliance, and Launch

**Goal**: The site is legally compliant, correctly indexed in three language variants, analytics fire only after consent, and every page scores Lighthouse > 90
**Depends on**: Phase 2
**Plans**: 3 plans

Plans:

- [x] 03-01: SEO layer and webhook — NAP constants, generateMetadata with hreflang on all pages, JSON-LD (Restaurant + Menu), sitemap.xml, robots.txt, HMAC webhook handler
- [x] 03-02: Compliance — cookie consent banner (3 languages, Consent Mode v2, equal-prominence accept/reject), GTM/GA4 consent-gated, four legal pages in FR/EN/DE
- [x] 03-03: Performance audit and verification — bundle analysis, Lighthouse audit, static generation check, CLS verification, ISR end-to-end, human verification checkpoint

**Details:**
- `revalidateTag` in Next.js 16 requires second profile argument — used `{ expire: 0 }` for immediate invalidation
- `schema-dts` DayOfWeek requires full IRI format (`https://schema.org/Tuesday`) not plain strings
- NAP dual-source pattern — `seo.ts` constants for SEO/JSON-LD, Sanity siteSettings for editorial — both must match
- Consent Mode v2 defaults must be in synchronous `<script>` in `<head>` BEFORE GTM loads
- Legal pages use `revalidate=false` for permanent caching
- CookieBanner uses `position: fixed bottom-0` for zero CLS impact
- Shared framework baseline ~220KB gzipped is irreducible (React 19 + Next.js 16 + next-intl + motion)

## Milestone Summary

**Key Decisions:**

- Next.js 16 App Router with Turbopack — chosen for ISR, proxy.ts middleware, and Vercel-native deployment
- Sanity v5 with field-level `localeString` i18n (NOT `@sanity/document-internationalization`) — simpler, sufficient for 3 locales
- `motion` package (import from `motion/react`), NOT `framer-motion` — Next.js 16 compatible tree-shakable build
- Tailwind configured via `@theme {}` in CSS, NOT `tailwind.config.js` — v4 CSS-first approach
- Single hero fixed image, no slider — protects Core Web Vitals
- Obypay removed, Gusty consolidated for reservation + Click & Collect
- Catch-all try/catch on Sanity fetch — prevents build failure with placeholder credentials
- Docker deployment with standalone output on VPS srv1417179 (valid until 2027-02-23)

**Issues Resolved:**

- `__experimental_actions` deprecation in Sanity v5 → singleton via `structure.ts`
- `priority` prop deprecated in Next.js 16 `next/image` → `loading=eager`
- `@sanity/image-url` default export deprecation → `createImageUrlBuilder` named export
- Turbopack worker race on WSL2 → `NEXT_TURBOPACK_USE_WORKER=0`
- `revalidateTag` API change in Next.js 16 → `{ expire: 0 }` profile argument

**Issues Deferred:**

- Gusty Click & Collect URL pending from owner (Sanity placeholder in place)
- Final photo selection from Nis&For preselection (29 photos, placeholders in build)
- Live Lighthouse > 90 verification on Slow 4G (requires production deployment)
- Google Rich Results Test on live URLs (requires production deployment)

**Technical Debt Incurred:**

- SEO-07: Footer uses static text for NAP, not wired to `seo.ts` NAP constants. NAP correct via JSON-LD; cosmetic inconsistency only.
- PERF-05: First-load JS baseline ~220KB gzipped > 150KB target. Next.js 16 + React 19 + next-intl + motion framework floor — acknowledged irreducible.
- bundle-analyzer: `@next/bundle-analyzer` in devDependencies but not wired into `next.config.ts` (on-demand via `ANALYZE=true` env var only).
